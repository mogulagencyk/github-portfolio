# Kathan Arvie | Technology Portfolio

Professional portfolio for COSC 4272 Senior Seminar.

**Portfolio:** https://mogulagencyk.github.io/github-portfolio/

Features:
- Responsive portfolio with About, Projects, Skills, Resume, and Contact sections
- Projects: Mogul Agency, Shop Mogul, Moguls Academy, Job Fit Analyzer
- Job Fit Analyzer: a fully client-side, rule-based job description analyzer developed with AI assistance
- Resume and assignment documentation

## Setup
Enable GitHub Pages in Settings → Pages → Deploy from a branch → main → /(root).

## Before class submission
Add actual site screenshots, a professional photograph, verify credentials and contact information, and upload the PDF resume and supporting PDFs from the downloadable portfolio archive. The Job Fit Analyzer uses deterministic keyword matching, not an AI model at runtime.

## Source files
- `index.html`: portfolio
- `ai-project/index.html`: job analyzer
- `resume.md`: readable resume draft
- `docs/`: project documentation, prompt log, analyses

Created for Lamar University COSC 4272 Senior Seminar.
